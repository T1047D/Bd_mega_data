# BD MEGA DATA — Frontend v1

This is a static frontend preview built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — responsive design
- `app.js` — demo data and frontend interactions

## Run
Open `index.html` in a browser, or publish the three files to GitHub Pages.

## Important
- All 12 directory records are illustrative demo records, not real verified listings.
- No database, admin authentication, or API is connected yet.
- Before publishing real records, verify source, reuse license, accuracy and privacy.
- Do not put API keys, service-role keys, passwords or private data in frontend JavaScript.

## Next development phase
Connect a database and build secure admin authentication, source tracking, data import, record review and public search APIs.
